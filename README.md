# Лабораторная работа № 2: шифр Виженера

Программа шифрует и расшифровывает сообщения методом Виженера.
Поддерживает английский и русский алфавиты (включая «ё»), сохраняет
регистр, пробелы, цифры и знаки препинания. Буквы сообщения и ключа
должны принадлежать одному алфавиту. Небуквенные символы не расходуют ключ.

## Запуск

Требуется Python 3. Дополнительные библиотеки не нужны.

```bash
python main.py
```

Выберите `1` для шифрования или `2` для расшифровки, затем введите
сообщение и ключ. Для расшифровки используется тот же ключ.

Пример: `ATTACK AT DAWN` с ключом `LEMON` → `LXFOPV EF RNHR`.
